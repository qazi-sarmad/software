## Ignore

`docs/archive/` — 63 documents from before the audit. Each carries a stale banner. They contain
confident Present/Partial/Missing claims that the audit proved false. **Do not cite them as evidence
that anything works.**

## The one rule

Verify wiring by grepping the call site. A green test is not proof; on this repository the test suite
ran against a demo seed for months while the production build showed empty screens.
